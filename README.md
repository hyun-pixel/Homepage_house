# 도현종합건설 홈페이지

고급 맞춤 주택을 소개하는 고객용 홈페이지 데모입니다. 메인·주택 상세·전화 상담 예약 화면으로 구성했습니다.

## 실행

1. 저장소를 내려받습니다.
2. `dist/index.html`을 Chrome 또는 Edge에서 엽니다.
3. `dist` 안의 파일과 `assets`, `docs` 폴더를 함께 보관합니다.

설치나 빌드 과정이 없는 HTML·CSS·JavaScript 홈페이지입니다. 정적 호스팅을 연결할 때 제공할 폴더는 `dist`입니다.

## 화면 구성

- 메인: 전체 화면 스크롤 영상, 명조 제목, 회사의 약속, 대표 주택, 4단계 과정, FAQ와 상담 연결
- 주택 상세: 외관부터 정원까지 큰 사진 여섯 장, 공간 설명, 바로가기와 사진 확대
- 상담 예약: 가상 정보 입력, 희망 일시 선택, 오류 안내, 완료·초기화 체험
- 애니메이션: 사진 펼침, 제목 전환, 순차 등장, 메뉴·FAQ·사진 확대·버튼 반응
- 접근성: 키보드 초점, 움직임 줄이기 설정과 영상 실패 시 대체 화면

## 주요 파일

- `dist/index.html`, `dist/house.html`, `dist/consultation.html`: 세 페이지
- `dist/styles.css`, `dist/experience.css`: 화면 스타일
- `dist/site.js`, `dist/hero.js`, `dist/motion.js`: 화면 동작
- `dist/assets`: 웹용 영상·사진·로컬 글꼴과 라이선스
- `dist/docs`: AI 미디어 제작 프롬프트와 글꼴 안내
- `dist/README.html`, `dist/README.txt`: 자세한 사용 안내

## 데모 안내

실제 예약·문의는 접수되지 않습니다. 가상 정보로 체험해주세요. 입력 내용은 저장하거나 외부에 전송하지 않습니다. 주택 사진·영상과 계획 조건은 AI 가상 콘셉트이며 실제 시공 사례나 시공용 도면이 아닙니다.

히어로 영상은 화면 비율에 맞춰 확대됩니다. 모바일에서는 영상의 중심부가 크게 보이며, 본문 사진은 전체 비율을 유지합니다.

Pretendard와 Noto Serif KR은 로컬로 제공하며 해당 라이선스를 `dist/assets`에 포함했습니다. 명조 글꼴은 현재 화면의 문자 집합에 맞춘 파일이므로 새 제목을 추가할 때 문자 집합을 갱신해야 합니다.

## 확인한 범위

Chrome의 320·360·390·430·768·1024·1280·1440·1920px 화면과 200% 확대에 해당하는 배치를 확인했습니다. 스크롤 영상의 정·역방향, 메뉴·키보드·사진 확대·FAQ, 가상 상담 오류·완료·초기화, 움직임 줄이기와 로딩 실패 대체를 검증했습니다. 실제 휴대폰·Safari 확인은 후속 항목입니다.

현재는 홈페이지 소스를 제공하는 저장소입니다. 실제 예약 연결과 홈페이지 공개 배포는 별도 작업입니다.

최종 화면 검토(v9): 작은 화면의 제목 줄바꿈, 안내 글자, 버튼 터치 영역과 문구를 다듬었습니다. 최종 보정본은 main 단일 브랜치에서 관리합니다. 실제 홈페이지 공개 배포는 별도 작업입니다.
